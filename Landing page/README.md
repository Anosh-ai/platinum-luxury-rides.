# Platinum Luxury Rides — Landing Page

Premium cinematic landing page for **Platinum Luxury Rides**.

## Phase 1 status

Architecture, Vite/React/TypeScript/Tailwind scaffold, folder structure, typed content stubs, and asset slots are in place.

**Not started (Phase 2+):** section UI, visual styling beyond design tokens, GSAP timelines, Motion interactions, real fleet/copy content.

## Stack

- Vite + React 19 + TypeScript
- Tailwind CSS v4
- GSAP (installed; timelines deferred)
- Motion for React (installed; interactions deferred)

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Project layout (summary)

- `src/pages` — page composition
- `src/sections` — landing blocks (empty shells for Phase 2)
- `src/components` — shared UI / media / fleet primitives
- `src/content` — presentation-free data (empty until client-approved)
- `src/lib/animations` — GSAP utilities (stubs only)
- `public/assets` — brand, images, video, audio + `ASSET_SOURCES.md`

See `ANALYSIS.md` for reference-site findings and open client questions.
