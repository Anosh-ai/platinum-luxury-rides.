## Sourcing checklist (Phase 2)

1. Prefer client photography of the real Platinum fleet.
2. If using stock: download from Unsplash, Pexels, or Pixabay; paste URL, author, and licence in this file.
3. Prefer WebP/AVIF derivatives for delivery; keep a high-quality master.
4. Hero still should support dark cinematic treatment (headlights, wet road, smoke/atmosphere).
5. Never use Red Carpet Rides Melbourne CDN images or branding assets.
